# 똑보 — 줄 없이 보고하기

강남구청 대면보고 대기 서비스. 직원은 자리에서 보고실 줄을 서고, 실시간 순번을 보다가 차례가 오면 앱 알림과 문자(솔라피)로 호출받는다.
요구사항은 상위 폴더의 `스마트_보고대기_시스템_PRD_v2.md`(v2.1)를 따른다.

## 실행

```bash
npm install
npm run dev          # http://localhost:3000
```

DB 설정 없이 바로 뜬다. 기본 DB는 프로세스 안에서 도는 PostgreSQL(PGlite, `./.data/pglite`)이고, 첫 실행 때 데모 조직·보고실이 들어간다.
로그인 화면에서 사용자를 골라 들어간다(개발용, SSO로 교체 예정).

| 역할 | 데모 계정 | 들어가는 화면 |
|---|---|---|
| 직원 | 김민수 외 5명 | `/home` 보고실 카드·줄서기 → `/r/:id` 내 대기현황 |
| 비서실 | 한비서(행정국장실), 오비서(부구청장실·구청장실) | `/desk/:roomId` 대시보드 |
| 현황판 | 행정국장실 현황판 | `/board/:roomId` (번호만 표시) |
| 관리자 | 시스템관리자 | 모든 보고실 대시보드 |

운영 실행: `npm run build && SESSION_SECRET=... npm start` (환경변수는 `.env.example` 참고).

## 구조

```
src/lib/queue/service.ts    대기열 규칙: 줄서기·미루기(5회)·호출·긴급삽입·보류·상태 전이, 단계형 알림 판정
src/lib/queue/estimate.ts   예상 호출 시각 계산 (순수 함수)
src/lib/queue/notify.ts     알림 아웃박스 적재 (dedupe 키로 단계당 1회)
src/lib/messaging/          문자 문구, 솔라피 어댑터, 아웃박스 워커, 수신 결과 조회·웹훅
src/lib/db/                 PGlite/PostgreSQL 겸용 클라이언트, 마이그레이션, 데모 시드
src/lib/realtime/bus.ts     변경 알림 버스 → /api/stream (SSE)
src/app/api/                REST API (권한은 서비스 계층에서 보고실 단위로 재확인)
src/app/{home,r,desk,board,c,settings}  화면
```

설계 메모
- **동시성**: 모든 대기열 변경은 보고실 행을 `FOR UPDATE`로 잠근 트랜잭션 안에서 처리한다. 활성 신청 1인 1건은 부분 유니크 인덱스로도 막는다.
- **알림**: 순번 변동으로는 알림을 만들지 않고, 준비·임박·호출·변경 단계 진입 때만 `dedupe_key`로 1회 적재한다. 문자는 아웃박스 → 워커 → 솔라피 → 수신 결과 조회(15초)·웹훅 순서로 처리하며 3회 실패 시 `failed`로 남겨 비서실에 "전화로 호출" 안내를 띄운다.
- **개인정보**: 직원·현황판 API는 다른 사람의 이름·제목을 돌려주지 않는다. SSE는 "무엇이 바뀌었는지"만 보내고 데이터는 권한이 적용된 API로 다시 읽는다. 문자 본문과 1회용 링크 화면에는 보고 제목을 넣지 않는다.
- **1회용 호출 링크** `/c/:token`: 해시만 저장하고, 해당 호출 회차·호출 상태·30분 이내일 때만 응답을 받는다.

## 아직 남은 일 (PRD §13 결정 대기)

- **문자 실발송**: `.env.local`에 `MESSAGING_PROVIDER=solapi`와 솔라피 키·등록 발신번호를 넣으면 실제로 나간다. 키는 공개 레포에 절대 커밋하지 않는다.
- **인증**: 개발용 사용자 선택 로그인. 구청 SSO 방식이 정해지면 `src/lib/auth.ts`만 교체한다.
- **웹 푸시(브라우저를 닫아도 오는 알림)**: 현재는 앱이 열려 있을 때의 화면·OS 알림만 있다. 서비스워커 + VAPID 웹 푸시는 다음 단계.
- **다중 서버**: 실시간 버스가 프로세스 내부용이다. 서버를 여러 대로 늘리면 PostgreSQL LISTEN/NOTIFY로 바꾼다.
- 관리자 화면(조직·보고실 설정), 통계.
- 다른 보고실에서 호출 중일 때 "곧 다른 보고 진행 중" 표시 (PRD §5.1).
- 세션은 서명 쿠키(무상태)라 로그아웃해도 기존 토큰이 만료(12시간) 전까지 유효하다. SSO 연동 때 서버 세션으로 바꾼다.
